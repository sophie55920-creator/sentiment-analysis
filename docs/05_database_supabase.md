# 05. Supabase 데이터베이스 설정

## 1. 테이블 스키마 (`sentiment_logs`)
SQL Editor에서 다음 DDL을 실행합니다:

```sql
create table sentiment_logs (
    id bigint generated by default as identity primary key,
    input_text text not null,
    sentiment text not null check (sentiment in ('positive', 'negative', 'neutral')),
    confidence integer not null check (confidence >= 0 and confidence <= 100),
    reason text not null,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 인덱스 생성
create index idx_sentiment_logs_created_at on sentiment_logs (created_at desc);
```

## 2. 보안 및 RLS (Row Level Security)
- 클라이언트 직접 쓰기를 막고 Vercel API 서버에서만 적재하므로, RLS 활성화 후 서버사이드 `SUPABASE_SERVICE_ROLE_KEY`를 사용해 안전하게 `insert`를 수행합니다.
